# STRIDE

First-person rooftop parkour speedrunner built with Three.js, TypeScript, and Vite.

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Controls

| Action | Key |
|---|---|
| Move | `W A S D` |
| Jump / Wall-Kick | `Space` |
| Slide / Slope Boost | `Shift` / `C` |
| Vault / Climb | Auto |
| Grapple | `RMB` / `LMB` / `E` |
| Restart Course | `R` |
| Last Checkpoint | `F` |
| Pause | `Esc` |
