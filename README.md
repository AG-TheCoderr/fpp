# STRIDE

you run on roofs. that's the game.

first person, white city, red bits you can actually grab. slide, vault, kick off a wall, throw a web if you pointed at a lip that isn't the floor. eight courses. some go up, some turn, one is just falling downhill for a while.

not a story. time your run, beat the ghost, don't eat pavement.

play it here if the deploy worked: https://ag-thecoderr.github.io/fpp/

times and settings live in the browser on that phone/pc. nothing is saved in the github files, so two people on two devices don't share a ghost.

## run it

```
npm i
npm run dev
```

`npm run build` if you want a folder to throw on pages.

## keys

wasd. space jumps / wall kicks. shift or c slides. vaults happen if you hit them. mouse or e for the hook. r restart, f last checkpoint, esc pause.

phone: left half is a stick, right looks, fat jump button. settings has sliders if your thumbs don't reach.

that's it. go.
